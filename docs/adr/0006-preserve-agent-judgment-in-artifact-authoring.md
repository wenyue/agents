# Preserve Agent Judgment in Rule and Skill Authoring

SmartKit authors each obligation through an Owner Gate, then projects Rules through a Policy Frame,
Skills through a supported Judgment-led, Procedure-led, or Hybrid shape, and Generation Contracts
through a Generation Frame. Judgment-led is the default: prescribed process needs evidence that
order changes correctness, safety, protocol compliance, coordination, recovery, or the accepted
outcome. This keeps runtime artifacts complete without turning increasingly capable Agents into
interpreters of unnecessary recipes.

The authoring models are temporary evidence, Rule/Skill reassignment remains an explicit ownership
decision when it conflicts with the requested or current owner, and `writing-for-agents` plus the
unified Acceptance Standard remain unchanged. `write-rules-and-skills` itself is Hybrid: owner and
shape selection use judgment; Pruning, machine validation, Semantic Review, Acceptance, and
correction retain their required order.
