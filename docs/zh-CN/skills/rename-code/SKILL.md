# 重命名代码

在已批准的兼容边界内，完整重命名一个明确的符号或路径。用语义证据证明符号身份，用精确的仓库
证据证明路径身份。

## 确立重命名

1. 阅读目标项目关于命名、API、生成文件和验证的说明。记录旧名称到新名称的映射、目标种类、请求
   范围和已经作出的兼容性选择。
2. 证明符号的声明和作用域，或路径精确的当前位置和目标位置。分离无关的同名身份，并确认目标位置
   不会与无关内容冲突。
3. 选择一条执行路径：
   - **快速符号路径：** 仅在目标为私有或仓库内部符号、有证据表明不存在外部使用方、项目级语义
     重命名操作支持其语言和作用域，且该名称不具备动态、生成、序列化、持久化、协议、配置或跨语言
     身份时使用。
   - **完整重命名路径：** 每次路径重命名以及不满足所有快速符号条件的符号重命名都使用此路径，
     包括公共 API、外部契约、生成名称、动态字符串查找，以及没有受支持语义重命名工具的符号。
4. 对完整重命名路径，完成目标的发现：
   - **符号：** 在可用时使用项目级引用工具。否则，将全词搜索与调用点、类型、import、继承、分派、
     配置、反射和注册证据结合起来。
   - **路径：** 检查仓库树、版本控制索引、import、manifest、构建文件、测试、脚本、文档链接和区分
     大小写的引用。内容搜索没有匹配项，不是完整的路径证据。
5. 对完整重命名路径，对声明或路径、引用、测试、文件名、注释、用户可见文本、动态字符串查找、
   外部契约和生成输出进行分类。只有身份、类型、调用点、配置或路径证据将文本匹配与目标关联时，
   才纳入匹配。
6. 写入前解决完整重命名的兼容性：
   - 只有证据表明没有外部使用方时，才完整重命名私有或仓库内部身份；
   - 对公共 API 或外部契约，说明影响，并向其 owner 取得缺失的兼容性决策；
   - 除非已批准范围包含序列化键、协议字段、持久化名称、数据库列和配置键，否则保留它们；
   - 只有已批准的兼容性选择要求 deprecated alias，且项目支持该迁移路径时，才创建 alias。
7. 对每个生成表面，确定其规范源 owner 和受支持的重新生成命令。对路径，确定仓库支持的移动机制；
   对于纯大小写重命名，确定安全的中间路径。

快速符号路径会减少发现和报告工作，但仍必须重新发现并运行项目要求的每项检查。如果目标身份、范围
或路径选择未解决，缺少公共兼容性决策，目标位置会冲突或无法安全移动，或者无法确定必需的生成源
owner 或重新生成命令，则写入前停止。把确切的缺失决策或证据交接给对应的契约、路径、生成器或项目
owner。

## 应用重命名

1. 对快速符号路径，使用受支持的语义重命名操作更新声明及其引用。
2. 对完整重命名路径，应用已批准的映射：
   - **符号：** 更新声明和每处已确认的语义引用。
   - **路径：** 通过受支持的机制移动精确源，并更新每处已确认的路径引用。对于纯大小写移动，使用
     已确定的唯一中间路径，绝不覆盖目标位置。
3. 只有证据将测试、文件名、注释、文档和镜像文本与同一目标关联时，才对它们重命名。
4. 对完整重命名路径，通过规范源 owner 修改生成名称，然后运行已经确定的生成器。

## 重新发现并验证

1. 对符号重复所选路径的语义发现；对路径重复精确的树、索引和引用发现。
2. 把每处剩余旧名称归类为有意保留的外部契约、无关身份或范围内遗漏的重命名。
3. 运行项目针对受影响表面要求的每项检查，包括适用的格式化、静态分析、生成输出检查和受影响测试。
4. 重新发现或验证找到范围内遗漏时，只有当前证据将它唯一关联到已批准重命名，才进行修正，然后重复
   受影响的发现和检查。相同 finding 原样复现或拟议修正不会改变候选时，以无进展判定失败。证据无法
   对必需 finding 分类，或修正需要扩大范围、不同的兼容性决策或其他 owner 的操作时，也判定失败并
   交接。

## 结束本次运行

- **完成：** 只有目标已使用批准名称、每处已确认引用都能解析、所有旧名称残留都已分类、生成输出
  为最新状态且全部必需检查通过时，才算完成。
- **写入后失败：** 必需验证仍未通过、无法将重命名与无关改动分开、已经无进展，或者完成工作需要
  未经批准的范围或契约变更时，判定失败。保留有用的部分状态。
- 写入后，失败优先于同时发生的写入前停止条件。

报告所选路径、被重命名的符号或路径、兼容性结果、受影响表面、使用的语义工具或生成器、修正、确切
检查及退出状态，以及未解决或未测试的表面。逐项列出仍标识目标的每处有意保留或未解决的旧名称，并
给出确切位置和分类。汇总无关的同名身份；快速符号路径重新发现无残留时，只需报告干净结果。为每个
失败或已交接条件指出下一 owner。
