# 沟通质量

强度：`Mandatory`

适用范围：所有沟通。

## 共同标准

- 保持事实、逻辑、领域和契约上的准确性。
- 当重要区别、关系、适用条件、必要结果、限定、例外、所有权、完成条件和停止条件可能改变解释或执行时，
  应作出足够明确的说明，使其只有一种预期解释或行动。
- 保持术语一致。清晰优先于简洁；只有在必要含义和边界保持完整时，才能缩短内容。
- 传达结论以及重要的支持证据、假设和不确定性，但不暴露私有思维链。

## 受众路由

- 面向用户时，使用符合用户技术理解程度的通俗语言，并简要解释必要的技术术语，但不得抹去会影响
  正确性的区别。
- 创建或实质性修改面向 Agent、旨在指导或约束其决策或行动的文档时，应用 `writing-for-agents`。
- 对同时面向人类和 Agent 的产物，将面向用户的指导应用于呈现，将 `writing-for-agents` 应用于实际生效的
  内容；面向人类的易读摘要不得替代或削弱实际生效的契约。
